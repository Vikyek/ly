# Ly Display Manager Fork Workspace Rules

## Build & Installation
- Build: `zig build -Doptimize=ReleaseSafe`
- Install script: `./install.sh`

## Custom Configuration Options
- `label_fg`: Controls in-box field labels color (`login:`, `password:`).
- `input_fg`: Controls in-box user input and password asterisks (`****`).
- `border_fg`: Controls login box border color.
- `fg`: Controls top/bottom bar headers and default text color.
